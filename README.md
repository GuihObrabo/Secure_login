# 🔐 SecureLogin — Front-End Authentication Demo

SecureLogin é um projeto demonstrativo de sistema de login desenvolvido com foco em **UX moderno**, **design profissional** e **lógica de autenticação front-end**, utilizando LocalStorage para simular sessões de usuário.

Este projeto foi criado com o objetivo de compor portfólio e demonstrar habilidades práticas em desenvolvimento front-end.

## 🛠️ Tecnologias Utilizadas
- HTML5  
- CSS3 (Design moderno, Dark Mode e Gradientes)  
- JavaScript (ES6+)  
- LocalStorage para persistência de sessão  

---

## ✨ Funcionalidades
- Autenticação simulada via LocalStorage  
- Persistência de login mesmo após recarregar a página  
- Página inicial (Dashboard) após login  
- Logout com limpeza de sessão  
- Layout responsivo  
- Interface moderna e profissional  

---

## 🎯 Objetivo do Projeto
Demonstrar:
- Organização de código
- Lógica de autenticação front-end
- Boas práticas de UI/UX
- Projetos prontos para apresentação em GitHub e LinkedIn

---

## 📌 Observações
- GitHub Pages não executa PHP, por isso o projeto foi estruturado para funcionar 100% no front-end.
- A estrutura permite fácil migração futura para autenticação real com back-end (PHP + MySQL).
